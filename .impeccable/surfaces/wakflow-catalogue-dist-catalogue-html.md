Scope: Wakflow product catalogue PDF (A4 portrait, 22 pages). Visitor mode: Persuade (sales catalogue read on phones).
Audience: Indian SME owners, non-technical. Job: see the suite, understand one product per page, book a demo. Proof: GSM/Tripwaley measured numbers from Part A only.

## Direction contract
THESIS: Each product is a spec sheet with a live screen — the product shown working, its features pinned to it like datasheet pin labels. Refuses the category default of icon-card grids and stock-photo SaaS brochures.
OWN-WORLD: Pinned Wakflow web brand: pure black ground, fine cyan 12% hairline grid, cyan→blue→purple gradient on product names only, orange gradient demo pill, green ticks, red problem quotes, grey body. Oxanium numbers and titles, DM Sans body, JetBrains Mono rails and measurements. Screens drawn as thin-stroke neon SVG devices with soft halos.
STORY: Reader sees one system (cover map), the journey (intro), the whole suite in two pages, then each product: what it does, what it fixes, what's inside, measured proof, how to start.
FIRST VIEWPORT: Cover — WAKFLOW wordmark top-left, huge gradient headline upper third, the 17-node system map filling the lower 55% with the core glowing, orange "Book a free demo" pill and wakflow.com bottom rail.
